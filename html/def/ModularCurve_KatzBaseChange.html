definition module

Base change of Katz modular forms along ring maps

Throughout, R_0 is a commutative ring, R_1 an R_0-algebra, and k\in\mathbb{Z}. The module first records the evident transfer of scalars: KatzModularForm.algebraThrough R₀ R₁ A is the R_0-algebra structure on an R_1-algebra A given by the composite R_0\to R_1\to A, algebraThrough_eq identifies it with any given R_0-algebra structure on A sitting in a scalar tower R_0\to R_1\to A, and algHomThrough views an R_1-algebra homomorphism as an R_0-algebra homomorphism for these structures. On this basis, base change is defined for the three kinds of Katz forms of the project. For g a Katz modular form of weight k over R_0 — a rule assigning to each R_0-algebra A and each Weierstrass curve W/A with \Delta_W a unit an element of A, compatible with R_0-algebra maps and scaling by (u^{-1})^{k} under a variable change with unit u — baseChange is the form over R_1 whose value on W/A for an R_1-algebra A is the value of g on W with A regarded as an R_0-algebra through R_1. The same recipe defines base change of KatzLevelPForms, where the test data also include a LevelPData D=(x_P,y_P,x_Q,y_Q) satisfying IsLevelPStructure, and of KatzGamma0Forms, which are level-p forms carrying as a field the property DependsOnlyOnSndLine.

The accompanying lemmas give: the definitional value formula; the equality baseChange_toFun of the base-changed value with the original one on an algebra A in a scalar tower R_0\to R_1\to A; additivity, compatibility with negation, subtraction, products of forms, and the rescaling (c\cdot F)_{R_1}=(\text{image of }c)\cdot F_{R_1} for c\in R_0; commutation with the swap of the two points and with the pull-backs from weight-k level-one forms to level-p and to \Gamma_0(p) forms; and the stability under base change of the invariance predicates DependsOnlyOnSndLine, DependsOnlyOnLines (values unchanged when the x-coordinates of the corresponding points are related by InLine) and SwapInvariant.

Relation to Mathlib

Mathlib has no notion of Katz modular form, level-p datum or \Gamma_0(p) form; those are the project's own, built on Mathlib's WeierstrassCurve and WeierstrassCurve.VariableChange. algebraThrough is the composite-of-algebra-maps structure RingHom.toAlgebra of Mathlib, kept as a reducible definition rather than an instance.

Where it is used

Katz forms over a ring with a base-change operation allow one to pass between forms over \mathbb{Z} or a localisation and forms over residue rings or p-adic coefficient rings, which is the setting in which mod p modular forms and their q-expansions are compared in the modularity arguments.

@[reducible] def KatzModularForm.algebraThrough (R₀ : Type u) [CommRing R₀] (R₁ : Type u)
    [CommRing R₁] [Algebra R₀ R₁] (A : Type u) [CommRing A] [Algebra R₁ A] : Algebra R₀ A :=
  ((algebraMap R₁ A).comp (algebraMap R₀ R₁)).toAlgebra

theorem KatzModularForm.algebraThrough_eq (R₀ : Type u) [CommRing R₀] (R₁ : Type u) [CommRing R₁]
    [Algebra R₀ R₁] (A : Type u) [CommRing A] [Algebra R₁ A] [h : Algebra R₀ A]
    [IsScalarTower R₀ R₁ A] : KatzModularForm.algebraThrough R₀ R₁ A = h :=
  Algebra.algebra_ext _ _ fun r => (IsScalarTower.algebraMap_apply R₀ R₁ A r).symm

def KatzModularForm.algHomThrough (R₀ : Type u) [CommRing R₀] (R₁ : Type u) [CommRing R₁]
    [Algebra R₀ R₁] {A B : Type u} [CommRing A] [Algebra R₁ A] [CommRing B] [Algebra R₁ B]
    (f : A →ₐ[R₁] B) :
    letI := KatzModularForm.algebraThrough R₀ R₁ A
    letI := KatzModularForm.algebraThrough R₀ R₁ B
    A →ₐ[R₀] B :=
  letI := KatzModularForm.algebraThrough R₀ R₁ A
  letI := KatzModularForm.algebraThrough R₀ R₁ B
  { (f : A →+* B) with
    commutes' := fun r => by
      show f ((algebraMap R₁ A) (algebraMap R₀ R₁ r)) = (algebraMap R₁ B) (algebraMap R₀ R₁ r)
      exact f.commutes _ }

def baseChange (g : KatzModularForm R₀ k) (R₁ : Type u) [CommRing R₁] [Algebra R₀ R₁] :
    KatzModularForm R₁ k where
  toFun A _ _ W hW := @KatzModularForm.toFun R₀ _ k g A _ (algebraThrough R₀ R₁ A) W hW
  map_toFun := by
    intro A B _ _ _ _ f W hW hW'
    exact @KatzModularForm.map_toFun R₀ _ k g A B _ (algebraThrough R₀ R₁ A) _
      (algebraThrough R₀ R₁ B) (algHomThrough R₀ R₁ f) W hW hW'
  toFun_variableChange := by
    intro A _ _ C W hW hW'
    exact @KatzModularForm.toFun_variableChange R₀ _ k g A _ (algebraThrough R₀ R₁ A) C W hW hW'
