Equivalences of restricted products: factorwise, reindexing, flattening, decompositions

Throughout, \Pi^{r}_{i}\,[R_i, A_i]_{\mathcal F} denotes the restricted product of a family R_i with respect to subsets (or sub-structures) A_i along a filter \mathcal F on the index type: families x with x_i \in A_i for \mathcal F-almost all i.

The first group of definitions varies the factors. Given bijections \varphi_i : R_{1,i} \simeq R_{2,i} such that \varphi_i restricts to a bijection of A_{1,i} onto A_{2,i} for \mathcal F-almost all i, Equiv.restrictedProductCongrRight is the induced bijection of restricted products, acting componentwise; MulEquiv, AddEquiv, RingEquiv and LinearEquiv versions upgrade this when the A_i are submonoids, subsemirings, or additive submonoids stable under the scalars. MulEquiv.restrictedProductUnits identifies the unit group of a restricted product of monoids with the restricted product of the unit groups (M_i)^\times taken with respect to the units of the submonoids A_i.

The second group varies the index. For e : \iota_1 \simeq \iota_2 with \mathcal F_2 = e_*\mathcal F_1 (respectively \mathcal F_1 = e^*\mathcal F_2), Equiv.restrictedProductCongrLeft' and Equiv.restrictedProductCongrLeft are the reindexing bijections, again with monoid, additive, ring and linear versions, together with the expected formulae for their values. Equiv.restrictedProductCongr and its algebraic analogues combine both, from data e, \varphi_i : R_{1,i} \simeq R_{2,e(i)} and an eventual bijectivity hypothesis, and send x to the family e(i) \mapsto \varphi_i(x_i). RingEquiv.restrictedProductCongr_bijOn_structureSubring records that if bijectivity holds at every index, the resulting ring equivalence carries the subring of elements lying in A_{1,i} for all i bijectively onto its counterpart.

The remaining definitions are structural decompositions: restricted products commute with binary products, with finite products and with matrix formation; RestrictedProduct.flatten, flatten_equiv and flatten_equiv' group the factors along a map f of index types with appropriate filter compatibility; and principalEquivProd, with its monoid, additive and module versions, identifies a restricted product along a principal filter \mathcal P(S) with \left(\prod_{i \in S} A_i\right) \times \prod_{i \notin S} R_i.

Relation to Mathlib

These are additions to Mathlib's RestrictedProduct theory, in the style of its basic API (map, mapAlong, inclusion, structureMap), supplying congruence, flattening and principal-filter decomposition equivalences.

Where it is used

Restricted products along the cofinite filter are the ambient model for rings of finite adeles and their matrix and unit groups; these equivalences are what permits reindexing, change of coefficient family, and the splitting of an adelic object into its finitely many distinguished components and the rest.

References

  1. A. Weil, Basic Number Theory, Grundlehren der mathematischen Wissenschaften 144, Springer, 1974

variable {ι : Type*}
variable {R₁ : ι → Type*} {R₂ : ι → Type*} {S₁ : ι → Type*} {S₂ : ι → Type*}

variable {A₁ : (i : ι) → Set (R₁ i)} {A₂ : (i : ι) → Set (R₂ i)}
variable {𝓕 : Filter ι}

@[simps]
def Equiv.restrictedProductCongrRight (φ : (i : ι) → R₁ i ≃ R₂ i)
    (hφ : ∀ᶠ i in 𝓕, Set.BijOn (φ i) (A₁ i) (A₂ i)) :
    Πʳ i, [R₁ i, A₁ i]_[𝓕] ≃ Πʳ i, [R₂ i, A₂ i]_[𝓕] where
  toFun := map (fun i ↦ φ i) (by filter_upwards [hφ]; exact fun i ↦ Set.BijOn.mapsTo)
  invFun := map (fun i ↦ (φ i).symm)
    (by filter_upwards [hφ]; exact fun i ↦ Set.BijOn.mapsTo ∘ Set.BijOn.equiv_symm)
  left_inv x := by ext; simp
  right_inv x := by ext; simp

def MulEquiv.restrictedProductUnits {ι : Type*} {ℱ : Filter ι}
    {M : ι → Type*} [(i : ι) → Monoid (M i)]
    {S : ι → Type*} [∀ i, SetLike (S i) (M i)] [∀ i, SubmonoidClass (S i) (M i)]
    {A : Π i, S i} :
    (Πʳ i, [M i, A i]_[ℱ])ˣ ≃*
      Πʳ i, [(M i)ˣ, (Submonoid.ofClass (A i)).units]_[ℱ] where
        toFun u := ⟨fun i ↦ ⟨u.1 i, u⁻¹.1 i, congr($u.mul_inv i), congr($u.inv_mul i)⟩,
          by filter_upwards [u.val.2, u⁻¹.val.2] using fun i hi hi' ↦ ⟨hi, hi'⟩⟩
        invFun ui := ⟨⟨fun i ↦ ui i, by filter_upwards [ui.2] using fun i hi ↦ hi.1⟩,
          ⟨fun i ↦ ui⁻¹ i, by filter_upwards [ui⁻¹.2] using fun i hi ↦ hi.1⟩,
          by ext i; exact (ui i).mul_inv,
          by ext i; exact (ui i).inv_mul⟩
        left_inv u := by ext; rfl
        right_inv ui := by ext; rfl
        map_mul' u v := by ext; rfl

end add_mul_equiv

variable {ι₁ ι₂ : Type*}
variable {R₁ : ι₁ → Type*} {S₁ : ι₁ → Type*} {R₂ : ι₂ → Type*} {S₂ : ι₂ → Type*}

variable {𝓕₁ : Filter ι₁} {𝓕₂ : Filter ι₂}
variable {A₁ : (i : ι₁) → Set (R₁ i)} {A₂ : (i : ι₂) → Set (R₂ i)}

@[simps! apply, simps -isSimp symm_apply]
def Equiv.restrictedProductCongrLeft' (e : ι₁ ≃ ι₂) (h : 𝓕₂ = 𝓕₁.map e) :
    Πʳ i, [R₁ i, A₁ i]_[𝓕₁] ≃ Πʳ j, [R₁ (e.symm j), A₁ (e.symm j)]_[𝓕₂] where
  toFun x := ⟨fun i ↦ e.piCongrLeft' _ x i, by
    have := x.eventually
    simp only [piCongrLeft'_apply, h, Filter.eventually_map]; grind⟩
  invFun y := ⟨fun j ↦ (e.piCongrLeft' _).symm y j, by
    have := y.eventually
    simp_rw [h] at this
    have := Filter.eventually_map.1 this
    simp only [piCongrLeft'_symm_apply]; grind⟩
  left_inv x := by
    ext i
    exact funext_iff.1 ((e.piCongrLeft' _).left_inv x) i
  right_inv y := by
    ext j
    exact funext_iff.1 ((e.piCongrLeft' _).right_inv y) j

@[simp]
theorem Equiv.restrictedProductCongrLeft'_symm_apply_apply (e : ι₁ ≃ ι₂) (h : 𝓕₂ = 𝓕₁.map e)
    (x : Πʳ j, [R₁ (e.symm j), A₁ (e.symm j)]_[𝓕₂]) (j : ι₂) :
    (restrictedProductCongrLeft' e h).symm x (e.symm j) = x j := by
  simp [restrictedProductCongrLeft'_symm_apply]

def Equiv.restrictedProductCongrLeft (e : ι₁ ≃ ι₂) (h : 𝓕₁ = 𝓕₂.comap e) :
    Πʳ i, [R₂ (e i), A₂ (e i)]_[𝓕₁] ≃ Πʳ j, [R₂ j, A₂ j]_[𝓕₂] :=
  ((e.symm).restrictedProductCongrLeft' (𝓕₂.map_equiv_symm _ ▸ h)).symm

@[simp]
theorem Equiv.restrictedProductCongrLeft_apply_apply (e : ι₁ ≃ ι₂) (h : 𝓕₁ = 𝓕₂.comap e)
    (x : Πʳ i, [R₂ (e i), A₂ (e i)]_[𝓕₁]) (i : ι₁) :
    (restrictedProductCongrLeft e h) x (e i) = x i :=
  restrictedProductCongrLeft'_symm_apply_apply e.symm (𝓕₂.map_equiv_symm _ ▸ h) x _
