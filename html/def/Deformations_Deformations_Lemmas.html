Auxiliary topological algebra lemmas for Galois deformation theory

This module collects general-purpose additions to the topological-algebra, local-ring and group-action APIs, of the kind needed to speak about continuous representations with values in matrix algebras over local topological rings. On the topological side: in a nontrivial T_0 topological commutative ring whose topology is linear (a neighbourhood basis of 0 by ideals) some maximal ideal is open; a continuous monoid homomorphism induces a continuous homomorphism on unit groups, and a continuous R-algebra homomorphism A \to B induces one M_n(A) \to M_n(B) for finite n; a continuous algebra homomorphism is reinterpreted as a continuous monoid homomorphism; a continuous homomorphism from a topological group to a monoid factors through the units; and the coercion M^{\times} \to M is continuous. For a discrete codomain, continuity at a point means that the map is eventually constant near it, and a homomorphism from a topological group (resp. ring) is continuous exactly when its kernel is open. A discrete topological group, equipped with its right uniformity, has the discrete uniformity; and if every neighbourhood of 1 contains a finite-index subgroup, then the whole group is totally bounded for that uniformity. A determinant map \mathrm{End}_A(M) \to A is continuous when the endomorphism ring carries the A-module topology, matrix algebras carry the module topology, and an algebra equivalence between two algebras with module topology is automatically a topological equivalence; also \mathrm{End}_A(A) \cong A as A-algebras.

On the algebraic side: locality of ring homomorphisms is transported along the identity, along composition, along the passage to the underlying ring homomorphism of a continuous algebra homomorphism, along ring equivalences, and holds for the residue map of a local ring; a surjective local homomorphism induces a surjection of residue fields. A ring homomorphism K \to L of fields induces a homomorphism of chosen algebraic closures compatible with the structure maps. Pointwise actions are provided on (continuous) monoid homomorphisms when the target carries a multiplicative-distributive action, conjugation gives a continuous constant-scalar action, and a multiplicative-distributive action becomes distributive on the additive copy of the monoid. Finally, a monoid acting by semiring automorphisms on L acts on normal intermediate fields and on rings of integers; the opposite of a subgroup has the same index (hence finite index is inherited); together with small compatibility facts about valuation subrings, subring structure maps, commuting scalars and number-field instances for finite intermediate fields.

Relation to Mathlib

All declarations are stated in Mathlib's own language and extend its API (topological rings and groups, module topologies, local homomorphisms, Galois actions, subgroup indices); no project-specific structure is introduced here.

Where it is used

These lemmas support the deformation-theoretic part of the formalisation, where Galois representations are taken with values in matrix groups over local topological rings and one must pass between continuity, openness of kernels, residue fields and module topologies.

lemma IsModuleTopology.continuous_det {A : Type*} [CommRing A] [TopologicalSpace A]
    [IsTopologicalRing A] {M : Type*} [AddCommGroup M] [Module A M]
    [TopologicalSpace (Module.End A M)] [IsModuleTopology A (Module.End A M)] :
    Continuous (LinearMap.det : Module.End A M →* A) := by
  classical
  by_cases H : ∃ s : Finset M, Nonempty (Module.Basis s A M)
  · obtain ⟨s, ⟨b⟩⟩ := H
    have : IsModuleTopology A (Matrix s s A) := IsModuleTopology.instPi
    have : ContinuousAdd (Module.End A M) := IsModuleTopology.toContinuousAdd A _
    letI e : Module.End A M ≃A[A] Matrix s s A :=
    { __ := algEquivMatrix b,
      continuous_toFun := continuous_of_linearMap (algEquivMatrix b).toLinearMap,
      continuous_invFun := continuous_of_linearMap (algEquivMatrix b).symm.toLinearMap }
    rw [e.symm.isQuotientMap.continuous_iff]
    convert continuous_id.matrix_det (R := A) (n := s) using 1
    funext M
    exact LinearMap.det_toLin b M
  rw [LinearMap.det, dif_neg H]
  exact continuous_of_const fun x ↦ congrFun rfl

lemma IsTopologicalGroup.totallyBounded {G : Type*} [Group G] [TopologicalSpace G]
    [IsTopologicalGroup G] (H : ∀ s ∈ nhds (1 : G), ∃ H : Subgroup G, H.FiniteIndex ∧ ↑H ⊆ s) :
    letI := IsTopologicalGroup.rightUniformSpace G
    TotallyBounded (Set.univ : Set G) := by
  letI := IsTopologicalGroup.rightUniformSpace G
  rintro s ⟨t, ht1, hts⟩
  obtain ⟨H, hH, hHs⟩ := H _ ht1
  have : Finite (Gᵐᵒᵖ ⧸ H.op) := Subgroup.finite_quotient_of_finiteIndex
  refine ⟨Set.range (MulOpposite.unop ∘ Quotient.out : Gᵐᵒᵖ ⧸ H.op → G),
    Set.finite_range _, fun x _ ↦
      Set.mem_iUnion₂_of_mem ⟨QuotientGroup.mk (.op x), rfl⟩ (hts (hHs ?_))⟩

    ← MulOpposite.unop_mul, ← Subgroup.mem_op, MulOpposite.op_inv, ← QuotientGroup.eq]
