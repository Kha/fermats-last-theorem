definition module

Logarithmic Mahler measure of multivariate complex polynomials

For n \ge 0, MvPolynomial.torusBox n is the box (0,2\pi]^n \subseteq \mathbb{R}^n, i.e. Set.pi Set.univ (fun _ ↦ Set.Ioc 0 (2 * π)), the parameter domain for the unit torus. The accompanying lemmas record that it is measurable, that its Lebesgue measure is (2\pi)^n (in ℝ≥0∞, after toReal, and as a Measure.real), hence nonzero and finite; that the restriction of Lebesgue measure to it is the product of the restrictions of Lebesgue measure on \mathbb{R} to (0,2\pi]; that it is contained in, and almost everywhere equal to, the closed box [0,(2\pi,\dots,2\pi)] which is the domain used by Mathlib's torus integral, with the resulting identification of set integrals and of integrability on the two sets; membership criteria for Fin.cons and for Fin.insertNth insertions; the identification of the image (equivalently the preimage under the inverse) of torusBox (n+1) under MeasurableEquiv.piFinSuccAbove with (0,2\pi] \times torusBox n; and the normalisation ((2\pi)^{-1})^n \int_{\text{torusBox } n} a = a for a constant a.

The main definition, MvPolynomial.logMahlerMeasure P for P \in \mathbb{C}[X_i : i \in \mathrm{Fin}\,n], is the real number ((2\pi)^{-1})^n \int_{\theta \in (0,2\pi]^n} \log \bigl\| P(e^{i\theta_1},\dots,e^{i\theta_n}) \bigr\|, the evaluation point being fun i ↦ circleMap 0 1 (θ i), which is shown to coincide with Mathlib's torusMap 0 1 θ. Since Real.log 0 = 0 and the Bochner integral of a non‑integrable function is 0, the definition is total. Further lemmas give continuity in \theta of the evaluation, measurability and almost everywhere strong measurability of the integrand, the pointwise bound \|P(z)\| \le \sum_{m \in \mathrm{supp}\,P} \|\mathrm{coeff}_m P\| on the torus, and the values m(0) = 0, m(C c) = \log\|c\|, m(1) = 0, m(c\,X^m) = \log\|c\|, m(X_i) = 0, together with m(P) = \log\|{\rm constantCoeff}\,P\| in the case n = 0.

Relation to Mathlib

Mathlib has the one-variable logarithmic Mahler measure Polynomial.logMahlerMeasure (a circle average of \log\|p(z)\|); this module supplies the several-variable analogue for MvPolynomial (Fin n) ℂ with the same normalisation, together with the box torusBox n = (0,2\pi]^n, which is compared here with the closed box used by Mathlib's torusIntegral/TorusIntegrable and with torusMap.

Where it is used

The logarithmic Mahler measure serves as the archimedean device for comparing the size of a polynomial's coefficients with the mean of \log|P| over the unit torus, the form in which archimedean height estimates for polynomials enter later parts of the development.

def torusBox (n : ℕ) : Set (Fin n → ℝ) := Set.pi Set.univ fun _ : Fin n ↦ Set.Ioc 0 (2 * π)

theorem torusBox_def (n : ℕ) :
    torusBox n = Set.pi Set.univ fun _ : Fin n ↦ Set.Ioc 0 (2 * π) := rfl

theorem mem_torusBox {θ : Fin n → ℝ} : θ ∈ torusBox n ↔ ∀ i, θ i ∈ Set.Ioc 0 (2 * π) := by
  simp [torusBox]

theorem measurableSet_torusBox : MeasurableSet (torusBox n) :=
  MeasurableSet.univ_pi fun _ ↦ measurableSet_Ioc

@[simp]
theorem volume_torusBox : volume (torusBox n) = ENNReal.ofReal (2 * π) ^ n := by
  simp [torusBox, volume_pi_pi, Real.volume_Ioc]

theorem volume_torusBox_toReal : (volume (torusBox n)).toReal = (2 * π) ^ n := by
  rw [volume_torusBox, ENNReal.toReal_pow, ENNReal.toReal_ofReal two_pi_pos.le]

@[simp]
theorem volume_real_torusBox : volume.real (torusBox n) = (2 * π) ^ n := by
  rw [measureReal_def, volume_torusBox_toReal]

theorem volume_torusBox_lt_top : volume (torusBox n) < ⊤ := by
  rw [volume_torusBox]
  exact ENNReal.pow_lt_top ENNReal.ofReal_lt_top

theorem volume_restrict_torusBox (n : ℕ) :
    (volume : Measure (Fin n → ℝ)).restrict (torusBox n) =
      Measure.pi fun _ : Fin n ↦ (volume : Measure ℝ).restrict (Set.Ioc 0 (2 * π)) := by
  rw [torusBox, volume_pi, Measure.restrict_pi_pi]

theorem volume_torusBox_ne_zero : volume (torusBox n) ≠ 0 := by
  rw [volume_torusBox]

theorem torusBox_subset_Icc : torusBox n ⊆ Set.Icc 0 (fun _ ↦ 2 * π) := fun _ hθ ↦
  ⟨fun i ↦ ((mem_torusBox.1 hθ) i).1.le, fun i ↦ ((mem_torusBox.1 hθ) i).2⟩

theorem torusBox_ae_eq_Icc : torusBox n =ᵐ[volume] Set.Icc (0 : Fin n → ℝ) (fun _ ↦ 2 * π) := by
  rw [volume_pi]
  exact Measure.univ_pi_Ioc_ae_eq_Icc

theorem setIntegral_torusBox_eq_setIntegral_Icc {E : Type*} [NormedAddCommGroup E] [NormedSpace ℝ E]

def logMahlerMeasure (P : MvPolynomial (Fin n) ℂ) : ℝ :=
  ((2 * π)⁻¹) ^ n * ∫ θ in torusBox n, Real.log ‖eval (fun i ↦ circleMap 0 1 (θ i)) P‖

theorem logMahlerMeasure_def (P : MvPolynomial (Fin n) ℂ) :
    P.logMahlerMeasure =
      ((2 * π)⁻¹) ^ n * ∫ θ in torusBox n, Real.log ‖eval (fun i ↦ circleMap 0 1 (θ i)) P‖ :=
  rfl

theorem circleMap_eq_torusMap (θ : Fin n → ℝ) :

  ext i; simp [torusMap, circleMap]

theorem norm_eval_circleMap_le_sum_norm_coeff (P : MvPolynomial (Fin n) ℂ) (θ : Fin n → ℝ) :
    ‖eval (fun i ↦ circleMap 0 1 (θ i)) P‖ ≤ ∑ m ∈ P.support, ‖coeff m P‖ := by
