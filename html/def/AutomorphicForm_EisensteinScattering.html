definition module

Scattering function of the SL(2,Z) real-analytic Eisenstein series

The module defines eisensteinScattering as the ratio of completed zeta values \varphi(s) = \frac{\Lambda(2s-1)}{\Lambda(2s)}, where \Lambda is Mathlib's completedRiemannZeta, i.e. the function whose value at s with \operatorname{Re} s > 1 is \pi^{-s/2}\Gamma(s/2)\zeta(s); eisensteinScattering_def records the defining equation. It also defines the predicate CompletedZetaConjSymm, asserting that \Lambda(\bar s) = \overline{\Lambda(s)} for every s \in \mathbb{C}; this is used as a named hypothesis, while completedRiemannZeta_conj_of_one_lt_re proves the same identity unconditionally for \operatorname{Re} s > 1 from the Dirichlet series expansion.

The accompanying theorems develop \varphi and some \Lambda-lemmas needed for it: \Lambda(s) = \zeta(s)\Gamma_{\mathbb{R}}(s) when s \neq 0 and \Gamma_{\mathbb{R}}(s) \neq 0; non-vanishing of \Lambda on \operatorname{Re} s \ge 1 and, by the functional equation, on \operatorname{Re} s \le 0; and \Lambda(2) = \pi/6. For \varphi there is complex differentiability at s under explicit hypotheses excluding the poles 2s-1, 2s \in \{0,1\} and the vanishing of the denominator, and in the usable form: differentiability at every s with \operatorname{Re} s > 1/2, s \neq 1. Further: \varphi(s) \neq 0 for \operatorname{Re} s \ge 1; the functional equation \varphi(s)\varphi(1-s) = 1 under non-vanishing of \Lambda(2s-1) and \Lambda(2s), and unconditionally when \operatorname{Re} s = 1/2; \varphi(1/2) = 1; the residue statement that (s-1)\varphi(s) \to 3/\pi as s \to 1 in the punctured neighbourhood filter, together with 3/\pi \neq 0 and (3/\pi)(\pi/3) = 1; unitarity \lvert \varphi(s)\rvert = 1 on \operatorname{Re} s = 1/2, assuming CompletedZetaConjSymm; and the failure of integrability of y \mapsto \lVert y^{s}\rVert^{2}/y^{2} on (T,\infty), T > 0, for \operatorname{Re} s = 1/2, since that function equals y^{-1} there.

Relation to Mathlib

Mathlib supplies \Lambda as completedRiemannZeta, together with its functional equation, its residue at 1 and the non-vanishing of \zeta on \operatorname{Re} s \ge 1; the scattering function itself, the predicate CompletedZetaConjSymm and the conjugation symmetry of \Lambda are not in Mathlib and are introduced here.

Where it is used

The scattering function is the factor through which the constant term of the real-analytic Eisenstein series for \mathrm{SL}_2(\mathbb{Z}), and hence the continuous part of the spectral side of the Selberg trace formula, is expressed; the non-integrability statement records that the constant term y^{s} on the critical line is not square-integrable against y^{-2}\,dy. This material is self-contained analytic number theory and does not feed into the modularity-lifting and level-lowering steps of the proof of Fermat's Last Theorem.

def eisensteinScattering (s : ℂ) : ℂ :=
  completedRiemannZeta (2 * s - 1) / completedRiemannZeta (2 * s)

theorem eisensteinScattering_def (s : ℂ) :

theorem eisensteinScattering_mul_one_sub (s : ℂ)
    (h1 : completedRiemannZeta (2 * s - 1) ≠ 0)
    (h2 : completedRiemannZeta (2 * s) ≠ 0) :
    eisensteinScattering s * eisensteinScattering (1 - s) = 1 := by

    div_self (mul_ne_zero h2 h1)]

theorem completedRiemannZeta_conj_of_one_lt_re {s : ℂ} (hs : 1 < s.re) :
    completedRiemannZeta (conj s) = conj (completedRiemannZeta s) := by
  have hπarg : Complex.arg (Real.pi : ℂ) ≠ Real.pi := by
    rw [Complex.arg_ofReal_of_nonneg Real.pi_pos.le]
    exact Ne.symm Real.pi_ne_zero
  have hs' : 1 < (conj s).re := by rwa [Complex.conj_re]
  rw [completedZeta_eq_tsum_of_one_lt_re hs, completedZeta_eq_tsum_of_one_lt_re hs',
    map_mul, map_mul]
  congr 1
  · congr 1
    ·
      have harg : -(conj s) / 2 = conj (-s / 2) := by
        rw [map_div₀, map_neg, map_ofNat]
      rw [harg, Complex.cpow_conj _ _ hπarg, Complex.conj_ofReal]
    ·
      have harg : (conj s) / 2 = conj (s / 2) := by
        rw [map_div₀, map_ofNat]
      rw [harg, Complex.Gamma_conj]
  ·
    have hterm : ∀ n : ℕ,
        (1 : ℂ) / (n : ℂ) ^ (conj s) = conj ((1 : ℂ) / (n : ℂ) ^ s) := by
      intro n
      rw [map_div₀, map_one]
      congr 1
      have hnarg : Complex.arg (n : ℂ) ≠ Real.pi := by
        rw [Complex.natCast_arg]
        exact Ne.symm Real.pi_ne_zero
      rw [Complex.cpow_conj _ _ hnarg, Complex.conj_natCast]
    calc ∑' n : ℕ, (1 : ℂ) / (n : ℂ) ^ (conj s)
        = ∑' n : ℕ, conj ((1 : ℂ) / (n : ℂ) ^ s) := tsum_congr hterm
      _ = conj (∑' n : ℕ, (1 : ℂ) / (n : ℂ) ^ s) := by
          simp only [starRingEnd_apply]
          exact tsum_star.symm

def CompletedZetaConjSymm : Prop :=
  ∀ s : ℂ, completedRiemannZeta (conj s) = conj (completedRiemannZeta s)

theorem eisensteinScattering_conj (h : CompletedZetaConjSymm) (s : ℂ) :
    eisensteinScattering (conj s) = conj (eisensteinScattering s) := by
  rw [eisensteinScattering_def, eisensteinScattering_def, map_div₀]
  congr 1
  · rw [← h (2 * s - 1)]
    congr 1
    rw [map_sub, map_mul, map_one, map_ofNat]
  · rw [← h (2 * s)]
    congr 1
    rw [map_mul, map_ofNat]

theorem norm_eisensteinScattering_critical_line (h : CompletedZetaConjSymm)
    {s : ℂ} (hs : s.re = 1 / 2) :
    ‖eisensteinScattering s‖ = 1 := by

  have hconj : (1 : ℂ) - s = conj s := by
    apply Complex.ext
    · rw [Complex.sub_re, Complex.one_re, Complex.conj_re, hs]
      norm_num
    · rw [Complex.sub_im, Complex.one_im, Complex.conj_im]
      ring

  have key := eisensteinScattering_mul_one_sub_of_re_eq_half hs
  rw [hconj, eisensteinScattering_conj h] at key

  have hnormsq : Complex.normSq (eisensteinScattering s) = 1 := by
    have h1 : ((Complex.normSq (eisensteinScattering s) : ℝ) : ℂ) = 1 := by
      rw [← Complex.mul_conj]
      exact key
    exact_mod_cast h1
  have hnorm' : ‖eisensteinScattering s‖ ^ 2 = 1 := by
    rw [← Complex.normSq_eq_norm_sq]
    exact hnormsq
  nlinarith [norm_nonneg (eisensteinScattering s)]

theorem not_integrableOn_norm_cpow_sq_div_sq {s : ℂ} (hs : s.re = 1 / 2) {T : ℝ}

  rw [integrableOn_Ioi_rpow_iff hT] at this
  linarith
